CONTAS EM DIA — GERAR O APK PELO CELULAR
=========================================

Nesta versão todos os arquivos ficam soltos, sem pastas. Assim dá para enviar tudo pelo celular.

1) DESCOMPACTAR
   - Abra o app Arquivos > Downloads (Transferências).
   - Toque em ContasEmDia-APK-celular.zip > Extrair.
   - Abra a pasta criada: devem aparecer 14 arquivos (index.html, package.json, apk.yml...).

2) CRIAR O REPOSITÓRIO
   - No Chrome, entre em github.com (se algum botão não aparecer, menu ⋮ > "Site para computador").
   - New repository > nome ContasEmDia-APK > marque Private > Create repository.

3) ENVIAR OS ARQUIVOS
   - Na página do repositório, toque em "uploading an existing file"
     (ou Add file > Upload files).
   - Toque em "choose your files", entre na pasta extraída, segure o dedo num arquivo
     e marque todos. Confirme.
   - Commit changes.

4) CRIAR O ARQUIVO QUE MONTA O APK
   - Add file > Create new file.
   - No nome, digite exatamente:  .github/workflows/apk.yml
     (ao digitar a barra, o GitHub cria as pastas sozinho)
   - Abra o arquivo apk.yml da pasta extraída, copie tudo e cole no GitHub.
   - Commit changes.

5) BAIXAR O APK
   - Aba Actions: "Gerar APK" roda por uns 5 a 10 minutos.
   - Verde: volte à página do repositório > Releases > ContasEmDia.apk.
   - Vermelho: abra a execução, copie o erro e me mande.

6) INSTALAR
   - Toque no ContasEmDia.apk baixado.
   - Permita "instalar apps desconhecidos" quando o Android pedir.
   - Se o Play Protect avisar: Mais detalhes > Instalar mesmo assim.
   - Abra o app > Ativar notificações > Permitir.
   - Samsung: Configurações > Aplicativos > Contas em Dia > Bateria > Sem restrições.

ATUALIZAR DEPOIS
   - Envie só o index.html novo (Add file > Upload files). O GitHub gera outro APK.
   - Instale por cima: os dados continuam.
